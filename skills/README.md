# Skills om te kopiëren

Hulpmiddelen voor wie zelf met Claude Code werkt in een project dat met Ello
gedeeld is.

## /cos-vraag (komt eraan)

Een skill die je in je eigen repo zet (`.claude/skills/cos-vraag/`). Typ
`/cos-vraag <onderwerp>` en je Claude bouwt met de context van je project een
kant-en-klare vraag voor de CoS: wat, waar, wat je zag, wat je al checkte.
Het resultaat stuur je zelf via WhatsApp; de CoS pakt zo'n vraag vrijwel
altijd zonder heen-en-weer op.

Status: in ontwikkeling. Zodra hij hier staat: map kopiëren naar je repo en
klaar.
